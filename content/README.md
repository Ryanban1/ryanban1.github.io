# Portfolio content (placeholders)

Everything in this folder is placeholder text. Replace anything in [square brackets] with real details.
The site build should read from these files so swapping in real content needs no code changes.

- `bio.md`: name, headline, short bio, contact links
- `experience.md`: jobs, internships, research, leadership
- `skills.md`: languages, hardware, tools, coursework
- `projects/`: one file per featured project, in display order (01 first)

Each project file starts with front matter (title, summary, tags, links, image) followed by
four recruiter-focused sections: Problem, My role, Tools, Results.
